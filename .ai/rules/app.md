# App

## Language and Comments Convention
AI agent instructions and user-facing messages are in Bahasa Indonesia. Code comments in controllers (GoogleController) use Indonesian. AI prompts reference UMKM (Usaha Mikro Kecil Menengah) context. Technical code comments and PHPDoc remain in English. Flash messages: 'Silakan lengkapi...', 'Data berhasil dikirim!', 'Gagal login menggunakan Google.'.
