# Project: KawanBisnis

Laravel Livewire platform for UMKM AI growth diagnosis. User-facing copy and AI system prompts are Bahasa Indonesia; write new code comments/PHPDoc in English.

## Stack

- Laravel 13 / PHP `^8.3` (CI + local: 8.5), Livewire 4, Filament 5 (`/admin`), Flux UI, Fortify + Socialite, Tailwind 4, Vite 8 via **vite-plus** (`vp build`/`vp dev` — not `vite` CLI)
- Testing: Pest 5, Larastan level 7, Pint (laravel preset)
- DB: SQLite default; tests `:memory:` (`phpunit.xml`)
- AI: Laravel AI, **OpenRouter only** (`config/ai.php`) — text `openrouter/free`, embeddings `nvidia/nemotron-3-embed-1b:free` (2048-dim). `OPENROUTER_API_KEY` required for real AI calls; tests never need it (see Testing).

## Commands

```bash
composer setup          # install, .env copy, key:generate, migrate, npm install, npm build
composer dev            # serve + queue:listen + npm run dev (needs Node; npx concurrently)
composer test           # config:clear → pint --test → phpstan → artisan test (order matters)
composer ci:check       # alias for composer test (what CI runs)
composer lint           # pint --parallel (fix)
composer types:check    # phpstan analyse
```

After editing PHP: `vendor/bin/pint --dirty --format agent`.

Single test: `php artisan test tests/Feature/ExampleTest.php` or `vendor/bin/pest tests/Feature/ExampleTest.php`; filter: `--filter=testName`.

**CI** (`.github/workflows/tests.yml`): PHP 8.5 + Node 22 → `composer setup` → `composer ci:check`. Never skip lint/types before tests.

## Instruction sources

- **`.ai/rules/`** — path-scoped rules auto-injected when editing matching files (see `.ai/rules/index.md`). Read the matching rule before editing that path. Hidden directory — globs may skip it.
- **`.agents/skills/`** — Laravel Boost skills (Livewire, Flux, Fortify, Tailwind, Pest, etc.); load when relevant. Regenerated by `php artisan boost:update` (runs on `composer update`).
- **`opencode.json`** — MCP: `php artisan boost:mcp`.
- **`README.md`** — architecture/routes/schema. Prefer executable config if docs conflict (AI models: `config/ai.php`).

## Architecture (non-obvious)

- **No REST API.** Full-page Livewire via `Route::livewire()` (`routes/web.php`, `routes/settings.php`).
- **AI pipeline is queued**: `SnapshotCreate` (or `DiagnosisShow` re-run) → `ProcessGrowthDiagnosisJob` (4 agents sequential: Analytics → Customer → Marketing → Strategy). Job clears prior `agent_analyses`/`action_plans` first so retries are idempotent. Diagnosis page polls until ready. Tests run `QUEUE_CONNECTION=sync`.
- **RAG**: `AgentKnowledge` + in-memory cosine similarity (`findSimilar()`, threshold 0.3, agents request top 3). Embeddings generated in Filament admin ("Generate Embedding").
- **Domain models**: `BusinessPassport`, `BusinessSnapshot`, `GrowthGoal`, `GrowthDiagnosis`, `ActionPlan`, `CheckInFeedback`, `AgentAnalysis`, `AgentKnowledge` (+ `User`).
- **Livewire**: `app/Livewire/{Dashboard,Settings,Landing,Actions}`; Flux (`flux:*`, `Flux::toast()`); Alpine for client JS.
- **Filament**: `/admin`, `AdminPanelProvider`; custom `AgentKnowledgeResource`. `composer install/update` runs `filament:upgrade` (post-autoload-dump). Access: only `users.is_admin = true` — `User` implements `FilamentUser::canAccessPanel()`; guests redirected to `/admin/login`, non-admins get 403 on panel and fail admin login (Livewire `Login::authenticate`). `is_admin` is **not** mass-assignable (not in `#[Fillable]`). Promote via factory `User::factory()->admin()`, seeder, or tinker: `User::where('email', $x)->update(['is_admin' => true])`. No dedicated admin guard — Filament uses default `web`.
- **Auth**: Fortify (login/register/2FA/passkeys); Google OAuth at `app/Http/Controllers/Auth/GoogleController.php` (`Controllers/Auth/`, not `Auth/`). `User` implements `PasskeyUser`; `google_id` and `password` nullable for OAuth users.
- **Models**: Laravel 13 `#[Fillable]`/`#[Hidden]` attributes (not `$fillable` arrays); `casts()` method on `User`, `$casts` property on others — match the file you edit.

## Testing

- `tests/Pest.php` auto-applies `RefreshDatabase` to **Feature** only (Unit does not get it — unit tests touching DB will fail).
- **AI is always faked**: pipeline tests use `AnalyticsAgent::fake([...])` / `CustomerAgent::fake` / `MarketingAgent::fake` / `StrategyAgent::fake` (Laravel AI fake), optionally `->preventStrayPrompts()`; RAG unit tests use `Embeddings::fake()`. Do not call real OpenRouter in tests.
- Factories: `database/factories/` for all domain models.
- New test: `php artisan make:test --pest SomeFeatureTest`.
- No external services needed (mail/array, cache/array, queue/sync in `phpunit.xml`).

## Gotchas

- `composer test` fails if lint or types fail first — run `composer lint` to fix style.
- Vite manifest missing → `composer setup` or `composer dev`.
- `composer dev` requires Node (npx concurrently).
- Prefer `config/ai.php` over prose for model names — `.ai/rules/config.md` / `.ai/rules/models.md` may have stale model/dimension claims; actual embedding dim is 2048.
- EditorConfig: 4-space, LF, UTF-8. Pint config: `pint.json`.
- `.npmrc` sets `ignore-scripts=true` (postinstall scripts skipped on npm install).
